# CSC1171-Project
CSC1171 group project: analysing which stress factors predict student stress level (Kaggle Student Stress Factors dataset, 1,100 students).

Research question: to identify if certain groups of factors from the given dataset are more strongly associated with student stress levels than other groups.
Main Result: From the analysis of this dataset, we found that no single group dominates in this regard. 
Team and module: David Lawley, Evan Byrne, Sean Summerville, DCU, CSC1171 Data Analytics & Data Mining.

Dataset: from Kaggle, titled "Comprehensive Analysis: Student Stress Datasets"
Link: https://www.kaggle.com/code/mdsultanulislamovi/comprehensive-analysis-student-stress-datasets/input
